## Über die App

LernappLAZ-BW ist ein privates, unabhängiges Lernprojekt zur Unterstützung beim Lernen für das Feuerwehr-Leistungsabzeichen Baden-Württemberg.

Die App wurde nicht im Auftrag einer Behörde oder der Landesfeuerwehrschule Baden-Württemberg entwickelt und ist keine offizielle App.

Entwickler und rechtlich verantwortlicher Anbieter ist **Louis Schmieg**.
