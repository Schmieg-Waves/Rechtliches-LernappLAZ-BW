## Über die App

LernappLAZ-BW ist ein privates Lernprojekt zur Unterstützung beim Lernen für das Feuerwehr-Leistungsabzeichen Baden-Württemberg. Die App wurde nicht im Auftrag einer Behörde oder der Landesfeuerwehrschule Baden-Württemberg entwickelt und ist keine offizielle App.

Entwickler und rechtlich verantwortlicher Anbieter ist **Louis Schmieg**.

Die HTML-Seiten dieses Repositorys werden über GitHub Pages veröffentlicht. Änderungen an den Rechtstexten müssen auch in der App nachvollzogen werden, damit die Angaben übereinstimmen und den tatsächlichen Funktionen und der Datenverarbeitung entsprechen.
